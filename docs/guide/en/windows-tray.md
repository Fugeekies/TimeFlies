# The Windows taskbar icon and notification

On Windows, TimeFlies has an icon in the notification area (next to the clock) as long as it runs, window open or closed.

## The icon

- **On hover**, it gives today's reminder: "TimeFlies — Intouchables: 15 years today".
- **Left click**: opens the window on [Today](today.md).
- **Right click**: **Open TimeFlies**, **Today's reminder** (the notification right away), **Settings** and **Quit**.

## Closing the window

By default, closing the window **hides** it: TimeFlies stays in the taskbar. To really stop it: right click on the icon › **Quit**. Untick **Keep TimeFlies in the taskbar when I close the window** in [Settings](settings.md#windows) so that closing the window quits the app.

## When Windows starts

With **Start TimeFlies when Windows starts** ticked, TimeFlies starts with Windows, window hidden, only in the taskbar. Starting it again from the Start menu brings its window back instead of opening the app a second time.

## The notification at start

When TimeFlies starts, with your PC or when you open it, a notification: "15 years today", with the event, its date and your age. Only once a day: if you start TimeFlies again the same day, nothing more. Clicking it opens Today.
