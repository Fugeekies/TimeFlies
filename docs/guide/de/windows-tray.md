# Das Taskleistensymbol und die Benachrichtigung unter Windows

Unter Windows hat TimeFlies ein Symbol im Infobereich (neben der Uhr), solange es läuft, ob das Fenster offen oder geschlossen ist.

## Das Symbol

- **Beim Darüberfahren** zeigt es die tägliche Erinnerung: „TimeFlies — Intouchables: heute 15 Jahre“.
- **Linksklick**: öffnet das Fenster auf [Heute](today.md).
- **Rechtsklick**: **TimeFlies öffnen**, **Erinnerung des Tages** (die Benachrichtigung sofort), **Einstellungen** und **Beenden**.

## Das Fenster schließen

Standardmäßig **versteckt** das Schließen das Fenster: TimeFlies bleibt in der Taskleiste. Um es wirklich zu beenden: Rechtsklick auf das Symbol › **Beenden**. Entferne den Haken bei **TimeFlies beim Schließen des Fensters in der Taskleiste behalten** in den [Einstellungen](settings.md#windows), damit das Schließen des Fensters die App beendet.

## Beim Start von Windows

Mit angehaktem **TimeFlies beim Start von Windows starten** startet TimeFlies mit Windows, Fenster versteckt, nur in der Taskleiste. Ein erneuter Start über das Startmenü holt sein Fenster zurück, statt die App ein zweites Mal zu öffnen.

## Die Morgenbenachrichtigung

Jeden Tag zur gewählten Uhrzeit (standardmäßig 9:00) eine Benachrichtigung: „Heute 15 Jahre“, mit dem Ereignis, seinem Datum und deinem Alter. War dein PC zu dieser Zeit aus oder im Ruhezustand, kommt sie beim ersten Aufwachen des Tages, nur einmal. Ein Klick darauf öffnet Heute.
