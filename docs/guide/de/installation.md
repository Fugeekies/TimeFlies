# Installation und erster Start

## Installieren

Jede Version wird auf der Seite [Releases](https://github.com/Fugeekies/TimeFlies/releases) veröffentlicht, mit einer Datei pro Plattform.

**Android** (ab 8.0)
1. Lade `TimeFlies-X.Y.Z.apk` auf dem Handy herunter und öffne die Datei.
2. Android fragt, ob dein Browser Apps installieren darf: Das ist normal für eine App, die nicht über den Play Store kommt.

**Windows** (10 und 11, 64 Bit)
1. Lade `TimeFlies-X.Y.Z-Setup.exe` herunter und starte es. TimeFlies wird für dein Konto installiert, ohne Administratorrechte.
   > Das Installationsprogramm ist nicht von einem bekannten Herausgeber signiert: Wenn Windows „Der Computer wurde durch Windows geschützt“ anzeigt, klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**.

## Erster Start

Der Bildschirm **Wir werden nicht jünger** erscheint nur einmal:

- **Dein Geburtsmonat und -jahr**: nie der Tag, mit Absicht. Damit wird dein Alter bei jedem Ereignis berechnet; die Angaben bleiben auf deinem Gerät.
- **Was dich interessiert**: eine Zeile pro Thema (Serien & TV, Kino, Musik…), mit seinem Inhalt und seiner Zahl an Ereignissen, alle angehakt. Entferne den Haken bei den Themen, die dich nicht ansprechen; die Details, etwa ein Land oder ein Genre, stellst du später unter [Einstellungen › Ereignisse](settings.md#ereignisse) ein.
- **Los geht's** speichert alles und öffnet [Heute](today.md).
- **Später** öffnet die App ohne Geburtsdatum: Die Jahrestage erscheinen ohne dein Alter. Du kannst es jederzeit in den [Einstellungen](settings.md) angeben.

## Aktualisieren, deinstallieren

- **Aktualisierung:** Wenn eine neue Version erscheint, zeigt Heute ein Banner **Neue Version**; **Herunterladen** öffnet ihre Seite. Installiere sie über die alte: Deine Einstellungen bleiben erhalten.
- **Deinstallation:** wie bei jeder App. Unter Android werden deine Einstellungen gelöscht; unter Windows (*Einstellungen › Apps*) bleiben sie in `%APPDATA%\TimeFlies` und werden bei einer Neuinstallation wiedergefunden.
